## Controle de Frota

Sistema de gerenciamento de frota desenvolvido para facilitar o cadastro e o acompanhamento de veículos, motoristas e abastecimentos, permitindo uma visão organizada dos gastos da operação.

## Sobre o projeto

O **Controle de Frota** é uma aplicação desenvolvida com Flutter e Laravel, com o objetivo de centralizar informações relacionadas à gestão de uma frota de veículos.

O sistema permite registrar abastecimentos, consultar históricos e acompanhar despesas por meio de um painel de resumo.

## Tecnologias utilizadas

- **Flutter e Dart:** desenvolvimento da interface.
- **Laravel e PHP:** desenvolvimento da API REST.
- **SQLite:** armazenamento dos dados.
- **Laravel Sanctum:** autenticação dos usuários.

## Funcionalidades

- Login e autenticação de usuários.
- Controle de acesso para administradores e usuários.
- Cadastro, consulta, edição e exclusão de veículos.
- Cadastro, consulta, edição e exclusão de motoristas.
- Registro e histórico de abastecimentos.
- Cálculo automático do valor total do abastecimento.
- Acompanhamento de gastos semanais e mensais.
- Cálculo da média mensal de gastos.
- Filtro de abastecimentos por mês e ano no painel.
- Painel com resumo geral da frota.

## Painel de resumo

O painel apresenta informações importantes para o acompanhamento da operação:

- Gasto no mês.
- Gasto na semana.
- Média mensal.
- Quantidade de abastecimentos no mês.
- Total de veículos e motoristas cadastrados.

Projeto acadêmico desenvolvido para aplicar conhecimentos de desenvolvimento de aplicações, integração entre frontend e backend, autenticação, banco de dados e gerenciamento de informações.
